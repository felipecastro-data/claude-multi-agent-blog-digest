## Securing the frontier: How JetBrains evaluates and deploys Claude Fable 5
Claude Fable 5 is now JetBrains' preferred model for complex coding tasks, achieving 44.3% pass rate versus 28.2% for Opus 4.8 on their private-repo Python benchmark while requiring 22% fewer steps to reach solutions. Use cases include long-running agentic coding, rich text editor implementation, cross-framework rewrites, and security testing. JetBrains emphasizes treating safeguards and data retention as central to secure deployment.

## Claude Tag now reads even more of the room
Claude Tag now evaluates broader channel context, memory, and standing instructions instead of analyzing individual messages, improving accuracy at deciding when to respond proactively by roughly 30%. It can recognize cross-cutting discussions and employ four response strategies: inline replies, threaded work, routing to existing workstreams, or staying silent. The feature is live for Claude Teams and Enterprise.

## Self-service data analytics in Slack: how Anthropic deploys Claude Tag for ad-hoc questions
Anthropic extended Claude Tag so non-technical employees can ask data analytics questions directly in Slack backed by governed data definitions, achieving roughly 95% accuracy via a semantic layer and skill files. Skill files refresh continuously to track data model changes and prevent stale answers, while access is deliberately scoped through a limited-permission service account. Structured logging tracks adoption and correctness through reaction feedback.
