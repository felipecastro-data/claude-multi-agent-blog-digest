## How Warp builds self-improving agents on Claude
- Warp (AI terminal, 800K developers) built a framework for self-improving agents using Claude
- Uses file-based "skills" that store domain knowledge separately from prompts, so agents can look it up rather than relying on static prompts
- Two-skill architecture: inner skill holds domain knowledge; outer "improver" skill observes feedback and proposes refinements
- Updates flow through standard code-review workflows, making improvements reviewable/mergeable
- Compounds agent quality over time instead of one-off, noisy first-pass output; now used across Warp's open-source repo with multiple specialized agents
