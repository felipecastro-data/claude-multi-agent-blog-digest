## How Warp builds self-improving agents on Claude
- Case study: Warp (AI terminal company) built a framework for self-improving Claude agents
- Problem: feedback on agent output vanished after each session, blocking continuous improvement
- Solution: two-skill architecture — an "inner skill" with domain knowledge and an "outer" observer agent that proposes updates from accumulated feedback
- Updates flow through normal code-review workflows and are inherited by future agent runs
- Applied across Warp's open-source repo for spec-writing, review, and triage agents; reusable pattern for other teams
