## The AI-Native SDLC playbook

- Identifies review, testing, and deployment (human-speed phases) as new bottlenecks, not code writing
- Introduces versioned artifacts (intent.md, spec.md, plan.md), skills as institutional knowledge, hooks as approval gates
- Autonomous loops close by triggering new work from production monitoring
- Aims to multiply engineering velocity while preserving governance/auditability for regulated enterprises
