## Claude's memory works everywhere, and you decide what's in it
- Anthropic unified Claude's memory system across chat, Claude Cowork, web, desktop, and mobile into a single continuous memory
- Memory now updates in real time as users chat, instead of only summarizing after a conversation ends
- Users can view, edit, and delete saved memories by topic in Memory settings; a single correction propagates to all future interactions
- Sensitive topics (health, religious beliefs, etc.) are excluded from memory by default; users can opt in with notification when such data is saved
- Reduces repetitive context-setting across platforms/conversations and improves consistency for teams (e.g., shared metric definitions in Cowork docs)
